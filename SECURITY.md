# Politique de sécurité

Pour signaler une faille, en privé : onglet « Security » du dépôt, puis « Report a vulnerability » (signalement privé de GitHub). Merci de ne pas ouvrir de ticket public.

Calendrier+ n'envoie aucune donnée de votre document à un service tiers ; la page n'appelle que son propre site et le script d'API de Grist (`docs.getgrist.com`), et sa politique de sécurité (`index.html`) ferme le reste.

---

# Security policy

To report a vulnerability privately: the « Security » tab of this repository, then « Report a vulnerability » (GitHub private reporting). Please do not open a public issue.

Calendrier+ sends no document data to any third-party service; the page calls only its own site and the Grist plugin API script (`docs.getgrist.com`), and its content security policy (`index.html`) closes everything else.
